# Dokumentacja tiny-voca (oryginał, po angielsku)

Te pliki pochodzą z [tiny-voca](https://github.com/n4ze3m/tiny-voca)
(Muhammed Nazeem, Apache-2.0) i opisują angielski model, na którym opiera się
słyszę głosy. Zostały bez zmian, jako opis architektury i adnotacji.

- [model.md](model.md): architektura modelu i dane tiny-voca.
- [annotations-v3.md](annotations-v3.md): jak powstały adnotacje długości
  głosek i kontrola jakości dopasowania.

Architektura i trening są tu takie same. Dane, głosy, front-end i progi
jakości są inne. Opisują je [README](../../README.md)
i [karta modelu](../model-card/README.md).
